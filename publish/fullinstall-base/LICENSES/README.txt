Night City Online - bundled component licences
==============================================

This package redistributes several independent Cyberpunk 2077 modding libraries,
unmodified, so that installation is a single step. They are not our work. Each one's
licence text is included in this folder.

Night City Online itself is an unofficial community build of CyberpunkMP
(https://github.com/tiltedphoques/CyberpunkMP), which is the work of Tilted Phoques
and contributors. It is NOT released by them.
