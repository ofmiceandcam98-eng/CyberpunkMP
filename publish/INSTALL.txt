================================================================================
  Night City Online  -  a multiplayer build of CyberpunkMP
  For Cyberpunk 2077 patch 2.5
================================================================================

  Discord:  https://discord.gg/M9NSWsndC7

  This is a work-in-progress multiplayer mod, and it is not finished. What is
  known to be broken in this release is listed in its notes:
      https://github.com/ofmiceandcam98-eng/CyberpunkMP/releases/latest


--------------------------------------------------------------------------------
  EASIEST: USE THE LAUNCHER, AND SKIP THE REST OF THIS FILE
--------------------------------------------------------------------------------

  Download and run the launcher:
      https://github.com/ofmiceandcam98-eng/CyberpunkMP/releases/latest/download/NightCityOnline-Setup.exe

  Sign in with Discord and press Install. It puts everything below in place,
  keeps it up to date, and starts the game with the right settings.

  The rest of this file is for installing by hand from this zip.


--------------------------------------------------------------------------------
  0. BEFORE YOU START
--------------------------------------------------------------------------------

  * You need Cyberpunk 2077 on PC, patch 2.5. Steam, GOG and Epic all work.
    Check your version at the bottom-left of the main menu.

  * BACK UP YOUR GAME FOLDER, or at least these subfolders:
        bin\x64
        engine
        r6
        red4ext
    Nothing here touches your saves, but a clean way back is worth two minutes.

  * ONLY IF YOU HAVE CYBER ENGINE TWEAKS: disable it.
    CET running alongside this mod once caused a full GPU hard-lock that needed
    a power cycle to recover from. That has not been re-tested since. To disable
    it without uninstalling, rename:
        bin\x64\version.dll   ->   bin\x64\version.dll.off

    IF THAT FILE DOES NOT EXIST, YOU DO NOT HAVE CET. Skip this step.
    Most people do not have it unless they installed it on purpose. Other
    signs of it: a bin\x64\plugins\cyber_engine_tweaks\ folder, or the "~"
    key opening a console overlay in game.

  * Vanilla stability first. If your game crashes without any mods installed,
    fix that before adding this - otherwise you will spend a night chasing the
    wrong bug. (One of us already did.)


--------------------------------------------------------------------------------
  1. INSTALL THE PREREQUISITES
--------------------------------------------------------------------------------

  Everything in the "prerequisites" folder is a separate, independently
  maintained mod that this one is built on top of. Install ALL SIX, in this
  order. Each one is a zip - extract it into your Cyberpunk 2077 folder so its
  contents merge with what is already there.

      1. RED4ext-1.31.0.zip
      2. redscript-0.5.32.zip
      3. Codeware-1.21.2.zip
      4. ArchiveXL-1.28.6.zip
      5. TweakXL-1.12.0.zip
      6. InputLoader-0.2.6.zip

  Your game folder is wherever Cyberpunk2077.exe lives, for example:
      C:\Program Files (x86)\Steam\steamapps\common\Cyberpunk 2077

  These are the exact versions this release is built against. Mixing in older
  or newer builds is the most common cause of "it just won't start".


--------------------------------------------------------------------------------
  2. INSTALL THE MOD
--------------------------------------------------------------------------------

  Copy the "mod" folder from this zip into:

      <your game folder>\red4ext\plugins\

  Then RENAME it to:

      zzzCyberpunkMP

  So you end up with:

      Cyberpunk 2077\red4ext\plugins\zzzCyberpunkMP\CyberpunkMP.dll
      Cyberpunk 2077\red4ext\plugins\zzzCyberpunkMP\assets\
      Cyberpunk 2077\red4ext\plugins\zzzCyberpunkMP\Rpc\

  The "zzz" prefix is not decoration - it makes this load last, after the
  libraries it depends on.


--------------------------------------------------------------------------------
  3. SET YOUR LAUNCH OPTIONS
--------------------------------------------------------------------------------

  The mod stays completely dormant unless you launch with --online. Without it
  the game runs exactly as normal, which is a handy way to test that your
  install did not break anything.

  Steam:  right-click the game -> Properties -> General -> Launch Options
  GOG:    Settings -> Features -> add to the command line
  Epic:   Settings -> Cyberpunk 2077 -> Additional Command Line Arguments

  Paste this, substituting the server address:

      --online --ip=SERVER_ADDRESS_HERE --port=11778

  For a server on your own machine:

      --online --ip=127.0.0.1 --port=11778

  *** THE "=" SIGNS MATTER. ***
  Writing "--ip 1.2.3.4" with a space instead of "=" silently fails. The game
  strips it, the mod never sees it, you connect to 127.0.0.1 instead, and you
  time out with no error explaining why. This cost us several hours. Use "=".

  Two dashes on --online, not one.


--------------------------------------------------------------------------------
  4. CONNECTING TO EACH OTHER
--------------------------------------------------------------------------------

  ONE person hosts. EVERYONE ELSE just joins.

  If you are JOINING (this is almost certainly you):
      Nothing extra to do. Follow sections 1-3, put the host's address in your
      launch options, and start the game. There is no server to run, nothing to
      install beyond the above, and no passwords to set. This package does not
      even include the server.

  If you are HOSTING:
      You need the server build, which is not in this zip - it comes from
      building the project, or from whoever runs the community server. The
      server is a separate program you leave running in its own console window
      while people play.

  The server listens on UDP port 11778.

  Over the internet, the easiest route is Tailscale (free, no port forwarding):
  everyone installs it, joins the same tailnet, and the host shares their
  Tailscale IP. Hamachi also works.

  If people cannot connect to your server, check the firewall FIRST. Windows
  auto-creates rules scoped to the "Public" profile, but Tailscale registers as
  "Private", so inbound traffic gets dropped with no message anywhere. The host
  needs to run this once, in an ADMIN PowerShell:

      New-NetFirewallRule -DisplayName "CyberpunkMP server" -Direction Inbound `
          -Protocol UDP -LocalPort 11778 -Action Allow -Profile Any

  Note: "ping" failing does NOT mean the tunnel is broken. Windows blocks
  inbound ICMP by default. Use "tailscale ping <address>" instead.


--------------------------------------------------------------------------------
  5. IF IT CRASHES - PLEASE SEND US THE LOG
--------------------------------------------------------------------------------

  This is the single most useful thing you can do for the project.

  The mod writes one log file per launch to:

      <game>\red4ext\plugins\zzzCyberpunkMP\logs\

  Files are named CyberpunkMP_<date>_<time>.log. Crashes no longer overwrite
  each other, so the file from the session that crashed is still there. Grab
  the most recent one and post the WHOLE FILE in the Discord.

  Not a screenshot, and not just the last few lines - the ordering across the
  whole log is what we read.


--------------------------------------------------------------------------------
  6. UNINSTALLING
--------------------------------------------------------------------------------

  Delete the zzzCyberpunkMP folder from red4ext\plugins, and remove --online
  from your launch options. The prerequisite mods are harmless to leave in
  place; they are used by plenty of other mods.

  Renaming the folder does NOT disable it - RED4ext scans every subfolder for
  DLLs. Move it out of plugins\ or delete it.
