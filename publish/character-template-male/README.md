# The male world template

The counterpart to `../character-template`. Players choose which one they load in the
launcher's Settings, under Character.

Made from `ManualSave-121` on 2026-08-15, using Phantom Liberty's quick start — which hands
you a level-15 V with Act 1 already marked complete, so this took minutes rather than a
playthrough.

| | |
|---|---|
| Body | **male** |
| Level / street cred | 15 / 15 |
| Act 1 | finished — 63 quests done |
| Position | Night City, told to head for Dogtown |
| Lifepath | Street Kid |
| Game version | 2310 (patch 2.31) |
| Modded | **no** |
| Requires | **Phantom Liberty** (`EP1`) |

Deliberately in the same world state as the female template: same quest, same 63 finished
quests, same level. Two players who pick different bodies should otherwise be standing in
identical worlds — if these ever drift apart, that difference becomes a bug somebody has to
find by noticing one player can reach something another cannot.

## Why body type is chosen in the launcher

It cannot be changed in game. Ripperdocs change everything about how you look **except**
body gender, and the mirror cannot do it either. It is fixed by the save the world is built
from, so the only place to decide it is before the game starts.

## Replacing it

Same bar as the other one, and all six are checked before shipping: **male**, **unmodded**,
**current game patch**, **past Act 1**, not point-of-no-return, not story mode. Every male
save on the machine this came from failed at least one - thirteen were modded and on patch
2.1, and the two clean ones were patch 1.6 prologue saves.

Drop the three files in and keep the folder name.
