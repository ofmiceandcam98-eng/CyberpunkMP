# Email to Nexus Mods support

Send to **support@nexusmods.com**. Change anything that does not sound like you — it is
better coming in your own words than mine.

Two things worth knowing before you send it:

- They may say no, or not reply. SSO registration is aimed at established mod managers,
  and Night City Online is new. Pasting an API key keeps working either way.
- Do not include an API key in the email. They never need one, and it would be a
  credential sitting in a support ticket.

---

**Subject:** SSO application registration request — Night City Online Launcher (Cyberpunk 2077)

Hello,

I run Night City Online, a small Cyberpunk 2077 multiplayer roleplay community built on
the open-source CyberpunkMP mod. I would like to request an SSO application registration
so players can authorise our launcher through the standard Nexus sign-in flow.

**What the launcher does**

It is an Electron application that gets players onto our server. It verifies their Discord
membership, installs and updates the multiplayer mod, and installs a small curated list of
Nexus mods that everyone on the server needs to be running the same versions of.

It is not a general-purpose mod manager and is not a competitor to Vortex. It installs one
specific list, chosen by our staff, for one community.

**How it uses the API**

- `users/validate.json` to confirm the key and show who is signed in
- `games/cyberpunk2077/mods/{id}.json` for mod names, versions and summaries, cached per
  session rather than re-fetched
- `games/cyberpunk2077/mods/{id}/files.json` to identify the current main file
- `download_link.json`, only in response to an `nxm://` handshake

**On downloads**

We register as an `nxm://` handler and only ever request a download link in response to a
link the user generated by pressing "Mod Manager Download" on your site. For free accounts
that means the download begins on your page, as intended — we do not attempt to work
around the Premium distinction, and the launcher tells players plainly that installing
opens Nexus.

We do not host, mirror or redistribute any Nexus file. The mod list stores mod IDs and
points at your pages; every download comes from you.

**What I am asking for**

An application slug we can pass as `application=` when opening
`https://www.nexusmods.com/sso`, so players can authorise in the browser rather than
copying an API key by hand. Currently the flow returns an authentication error, which I
assume is because the application is not registered.

Happy to provide anything you need, including the source — the launcher is part of a
public repository at https://github.com/ofmiceandcam98-eng/CyberpunkMP and I am glad to
make changes if anything above is not how you would like it done.

Thank you for your time, and for the API.
