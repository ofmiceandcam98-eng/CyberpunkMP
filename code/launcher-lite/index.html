Tools

01 ·Connection

3 tools · network
Join the server's network
Opens the network invite. You need this once, before the game server can reach you: accept the invite, then make sure Tailscale is switched to the network it joined.
Checkup
Runs the whole checklist at once - launcher, game, mod, frameworks, sign-ins, which server JACK IN goes to, and whether it answers. Runs by itself at startup; the button re-runs it.
Test server connection
Checks every link between this PC and the game server - internet, Tailscale, the server's network, the server itself - and names the first one that's broken and how to fix it.

02 ·Install

2 tools · nexus
Install everything
Downloads and installs the mod and all six required mods. Use this on a fresh setup.
Nexus Mods account
Needed to download the server's mod list.
Not signed in
1. Press Get my key - it opens your Nexus API page.
2. Scroll to Personal API Key and copy it.
3. Paste it below and press Save key.
One-click sign-in (needs Nexus approval)
Nexus only allows this for approved mod managers. It will fail until they whitelist Night City Online.

03 ·This PC

2 tools · windows
Desktop shortcut
Puts Night City Online Launcher on your Desktop and in the Start Menu. Windows will not let a program pin itself to the taskbar - right-click the shortcut and choose "Pin to taskbar" for that.
Developer overlay
Shows the in-game debug menu bar. Devs and admins only.
Launcher folder
Opens where the launcher is installed. The uninstaller lives here too.

04 ·Repair

4 tools · mod files
Verify game files
Checks the mod files are present and current. Reports everything wrong at once rather than one problem at a time.
Direct install from Nexus
Installs every mod on the server's list that is missing here, straight into the game folder. Premium Nexus keys download directly; free accounts get the mod page opened - press "Mod Manager Download" there and it lands here automatically either way.
Reinstall mod files
Re-downloads the current build over the top. Fixes a corrupted or partial install. Your other mods are not touched.
Deep clean
Hunts leftovers from old installs - stale data folders, dead Windows "Apps" entries, orphaned shortcuts, crash logs on the Desktop - and removes them after showing you the list. The uninstaller runs this same sweep, so uninstalling leaves nothing behind.

Dev

01 ·Dev tools

5 tools · devs only
Dev key
Paste this into your Claude so it can read and post updates alongside the others. Base URL and usage are shown once you reveal it.
Server
Which server Launch connects to. Leave blank to follow the published server - the main deployment everyone plays on, which redeploys itself from git. To use a test server, enter its host and port below and pair it with the matching build from Test builds.
Join the test server's network
Separate from the main invite - accepting that one does not get you here. You need this once before the test server can reach you.
Test builds
Pre-releases from GitHub. Players never see these - their launchers only auto-update from full releases. Install swaps in the test mod DLL and keeps the shipped one; Restore puts it back.
The Atlas
The mind map across every project - what is open, blocked, parked or just thought of, on the same board both assistants write to. The address fills itself in from your dev role; the box is there for overriding it.

01 ·Mod and launcher

3 actions · cannot be undone
Remove the mod
Deletes the multiplayer mod folder. Your game, saves and other mods are left alone.
Remove launcher files
Deletes your saved sign-in and settings. You will sign in again next time.
Uninstall launcher
Removes the launcher and everything it saved on this PC - your sign-in, settings, keys. Your game is left alone. Remove the mod first, above, if you want that gone too.
