Launcher · sizing only, not style

Type Scale

The launcher has 24 different font sizes in one window — .54, .55, .58, .6, .62, .64, .66, .68, .7, .72, .74… none of them chosen against each other. This is a proposal to collapse them onto seven steps. Same typefaces, same weights, same colours: only the sizes move.

What is in there now

Every distinct font-size in index.html, with how many rules use it. Nine rules agree on .72rem. The other fifteen sizes are used once or twice each — that is drift, not a decision.

The seven steps

Rendered at their real size. Each one keeps the job the sizes it absorbs were already doing.

--fs-micro.58rem 01/04 · READY · 102.6 MB Rail numbers, badges, small chips. Absorbs .54 .55 .58 .6 .62
--fs-label.68rem Repair and remove Section headings, tab labels, footer, admin labels. Absorbs .64 .66 .68 .7
--fs-small.74rem Re-checks the install against the manifest. Descriptions, status lines, notes, hints. Absorbs .72 .74 .75 .76 .78 — the biggest group in the app
--fs-body.84rem Verify game files Setting names, dropdowns, the lede paragraph. Absorbs .8 .82 .84 .85
--fs-lead1.02rem PLAY The Play button, and only that. Absorbs 1 1.02
--fs-head1.15rem Night City Online Brand, page title, modal title. Absorbs 1 1.15
--fs-icon1.2rem ⚙ × Chrome glyphs — the gear and the close. They are different sizes today (1.1 and 1.3) for no reason. Absorbs 1.1 1.3

What actually moves

Most of it is invisible — nineteen of the twenty-four sizes shift by half a pixel or less. These are the only changes you would notice.

Say go and every font-size in the file points at one of these seven tokens, so the next person adding a row picks a step instead of inventing a number. No typeface, weight or colour changes. The .72em on the Play button's chevron stays relative on purpose — it is sized against the button, not the page. Needs a launcher ship to reach anyone.
